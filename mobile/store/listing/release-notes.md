# Release notes ("What's new") — 1.0.0 (216)

Play Console → Release → "Release notes". Chegara: har til uchun **≤ 500 belgi**.
Pastdagi bloklarni o'zgartirmasdan nusxalang — Play teglar orqali tilni o'zi ajratadi.

## Angren Taxi (yo'lovchi)

```
<uz-UZ>
Angren Taxi'ning birinchi versiyasi!
• Taksi chaqiring — narx buyurtmadan oldin ko'rinadi
• Haydovchini xaritada real vaqtda kuzating
• Yuk va posilka tashish, ovqat va market buyurtmasi
• Safar davomida SOS tugmasi
• Hisobni Profil bo'limidan o'chirish mumkin
Fikringizni "Yordam" bo'limiga yozing — har bir xabarni o'qiymiz.
</uz-UZ>
<ru-RU>

• Вызов такси — цена видна до заказа

• Кнопка SOS во время поездки
• Аккаунт можно удалить в разделе «Профиль»

```
